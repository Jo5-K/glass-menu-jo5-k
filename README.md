# Glass Menu - Jo5-k — 0.1.7

## Português

Temas para menus fora da batalha. Configuração em **START → GLASS**: nove temas e texto separado (Nativo, Claro ou Escuro). Inclui Original, Glass, Marfim, GBA, Atual, Clássico, Flutuante, Emerald Verde e Emerald GBA. Preserva conteúdo, traduções, navegação e imagens de Pokémon. O tratamento de fundos abrange mochila, equipe, resumo, Pokédex, loja e outros painéis nativos. Algumas artes próprias podem permanecer nativas.

Requer **G1R 0.3.97+ / API 3**. FireRed, LeafGreen, Ruby, Sapphire e Emerald. Importe o ZIP da release no gerenciador de mods; para instalação manual, extraia a pasta `glass_menu_jo5k` em `mods/`. Ative o mod no gerenciador.

## English

Themes for field menus only. Open **START → GLASS** for nine themes and independent Native, Light or Dark text. Includes the original UI, glass styles and Emerald palettes. Keeps native content, translations, navigation and Pokémon artwork. Background treatment covers the bag, party, summary, Pokédex, shops and other native panels; some custom artwork may remain unchanged.

Requires **G1R 0.3.97+ / API 3**. Supports FireRed, LeafGreen, Ruby, Sapphire and Emerald. Import the release ZIP through the mod manager, or extract `glass_menu_jo5k` under `mods/` and enable it.

## 0.1.7 — Menus flutuantes / Floating menus

Pokédex, Trainer Card e PC receberam integração específica. As telas gerenciadas mantêm o mundo por baixo, com painéis translúcidos; Original continua nativo. Corrigidos identificadores da Pokédex de Hoenn, cartão e depósito de itens; fundos de frente/verso, botões, slots da equipe e escolha de caixas recebem o tema. Pokémon, retratos, textos e papéis de parede das caixas permanecem separados.

Dedicated integration for Pokédex, Trainer Card and PC. Managed screens keep the field underneath translucent panels; Original retains native presentation. Fixes Hoenn screen identifiers, card front/back surfaces, item storage, buttons, party slots and box-selection panels. Pokémon, portraits, text and box wallpapers stay separate.

See [changes and validation](docs/CHANGELOG.md). Only simulated tests and official loader checks were performed, not ROM/GPU or physical Android visual validation. / Consulte as mudanças e os testes; sem validação visual em ROM/GPU ou Android físico.
